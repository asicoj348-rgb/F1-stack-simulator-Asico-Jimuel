## Project Description
This project is a simple Stack Data Structure Simulator created using HTML, CSS, JavaScript, and jQuery. It demonstrates the basic operations of a stack, which follows the Last In, First Out (LIFO) principle. The project includes Push, Pop, Peek, and Clear operations.
